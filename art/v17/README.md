# V17 geometry corrections

The original generated artwork remains in `art/v16`. The recorded component
boxes and pose registrations in `geometry-review.json` describe this cleanup.
Whole connected figure outlines are extracted before sizing; text labels and
neighboring drawings are excluded. Blank inherited poses use complete prior
artwork, and Slash 099/100 share the complete kneeling drawing.

These records document the importer correction. They are not a standalone
ROM editor; use the pinned BPS patch and public patcher to reproduce v17.
