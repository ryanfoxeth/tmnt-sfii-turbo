## If private access is unavailable

A plain chat may be able to read public Markdown but cannot automatically access GitHub private repos, Dropbox, local files or a ROM. Give it the public start link plus the desired scoped task. For implementation, use an assistant with filesystem/tool access on the destination device and provide access to the private workbench/archive there. Do not publish the private archive as a workaround.
